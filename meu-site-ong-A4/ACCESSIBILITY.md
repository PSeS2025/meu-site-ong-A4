# Acessibilidade — ONG Esperança 🌍

O site da **ONG Esperança** foi desenvolvido com foco em **acessibilidade digital**, seguindo as recomendações da [WCAG 2.1](https://www.w3.org/TR/WCAG21/).

## 🧠 Recursos inclusivos implementados

- Navegação total via **teclado** (Tab / Shift+Tab)
- Link de **“Pular para o conteúdo”**
- **Alto contraste** e **modo escuro**
- Mensagens dinâmicas via `aria-live`
- **Validação de formulários acessível**
- **Foco visível** em todos os elementos interativos
- **Modal acessível** com foco controlado

## ♿ Testado com
- Navegação por teclado
- Leitores de tela (NVDA, VoiceOver)
- Modo de alto contraste no Windows
- Navegadores: Chrome, Edge e Firefox
